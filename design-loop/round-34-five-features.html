Round 34 · Five new features for My News and World Brief

One preview per feature. The NVDA and PTT earnings numbers are real (checked on Yahoo today). Story text, mood counts and places are examples. Everything here uses data the site already has, plus one new free Yahoo call for earnings.

1 · Send saved stories + notes to Obsidian

Your saved stories and your notes become one Markdown file in your vault's raw/ folder, following its rules (dated name, never edited later). Then saying "ingest" in Claude turns it into wiki pages.

HOW IT GETS THERE (pick one)
A · One command on your PC RECRun python robot/obsidian_export.py. It writes straight into second-brain/raw/. Only stories saved or noted since the last export, so no duplicates.
B · Download button"Export to Obsidian" in the Saved view downloads the same .md file. You move it into raw/ yourself. Also works from your phone.

5 · Earnings result card

When a watchlist company reports, a card appears at the top of My News for 3 days. It shows EPS actual vs expected, BEAT / MISS, the surprise %, revenue, and how the stock moved since the report. It also shows on that day in the Calendar. The robot checks Yahoo once a day per watchlist stock.

What gets built behind these:
  • One new SQL file (012): a follows table (stories + places) and an earnings_results table. You run it once.
  • Robot: follow alerts run every 30 minutes, and the earnings check runs once a day. Telegram goes to the same chat as your other alerts.
  • No new accounts, keys or costs. The only new outside call is Yahoo's earnings data (free; the robot already uses Yahoo for dates).
